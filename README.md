## 🔬 2. The Core Empirical Discovery: The "Dormant-Default" Paradox

Traditional growth strategies assume that gaining market share requires acquiring brand-new users through expensive sign-up cashbacks. Our analysis reveals that **Paytm already owns the users—it loses them at the physical point-of-sale**.

```mermaid
flowchart TD
    subgraph S1["1. USER FOUNDATION (High Penetration)"]
        A1["113 Surveyed Transactors"] --> A2["71 Users (64.0%) are Active on Paytm UPI"]
    end

    subgraph S2["2. THE CHECKOUT MOMENT (System-1 Decision)"]
        A2 --> B1{"Physical Retail Counter\n(Canteen / Kirana / Transit)"}
        B1 -->|"⚡ Fastest Tap (45.1% Speed/Ease)"| C1["Competitor Default (GPay / PhonePe)\nWins 84.7% of Primary Transactions"]
        B1 -->|"🐌 Cluttered UI / Perceived Latency"| C2["Paytm Relegated to Secondary App\nRetains only 15.3% Primary Share"]
    end

    subgraph S3["3. LONG-TERM VALUE EROSION"]
        C1 --> D1["Daily Micro-Payment Habit Solidified"]
        D1 --> D2["Downstream High-Ticket GMV Lost\n(Rent, Utilities, E-Commerce, P2P Transfers)"]
    end

    subgraph S4["4. THE INTERVENTION (Paytm TurboScan & SplitPass)"]
        E1["<300ms Lockscreen Scanner\n+ Soundbox Social Bill Split"] -.->|"Intercepts Checkout"| B1
        E1 ==>|"Captures 57.5% Dormant Pool"| F1["+₹5,246 Cr Annual Incremental GMV"]
    end

    style S1 fill:#f8fafc,stroke:#334155,stroke-width:1.5px
```

> [!IMPORTANT]
> **Key Finding on Rewards:** Only **$14.41\%$** of respondents select their primary app for offers/rewards. In contrast, **$77.48\%$** select their primary app based on **Speed/Ease ($45.05\%$)** and **Habit/Muscle Memory ($32.43\%$)**. Competitor cashbacks do not build defensibility; frictionless latency builds default habits.
